# ObjectProperty

_ObjectProperty_ is KingsIsle's runtime reflection and serialization system for
C++ classes.

It was initially written by [Richard Lyle](https://github.com/rlyle) as part of
the [Medusa project](https://github.com/palestar/medusa) (see `Reflection`
directory) and was later ported into KI's codebase with additional features and
improvements.

The [wizwalker](https://github.com/Starrfox/wizwalker.git) project's type dumper
utility may be used to obtain a full list of all reflected types from the game.
